# TogetherServe client

Next.js 16 App Router + React 19. JavaScript only (no TypeScript), Tailwind CSS v4 + daisyUI v5. Use npm (`package-lock.json` is the only lockfile).

## Commands

- `npm run dev` — dev server at http://localhost:3000.
- `npm run build` / `npm start` — production build / serve it.
- `npm run lint` — runs `eslint` (flat config) over the repo. Next 16 has no `next lint`; don't add it.
- Single file: `npx eslint src/app/page.js`.
- There is no test runner or typecheck script; don't invent `npm test` or `tsc`. Verify changes with `npm run lint` and `npm run build`.

## Structure

- App Router lives in `src/app/` (`layout.js`, `page.js`, `globals.css`). There is no `src/components/` yet.
- `@/*` maps to `src/*` via `jsconfig.json`.

## Styling quirks

- Tailwind v4 has no `tailwind.config.js`; theme and plugins are configured in CSS. `globals.css` uses `@import "tailwindcss"` and `@plugin "daisyui"`.
- `next.config.mjs` registers `@tailwindcss/turbopack` as a Turbopack rule for `*.css`. Don't move this into a JS Tailwind config.
- Brand palette tokens (`--together-green`, `--together-lime`, `--together-cream`) are in `globals.css`; the landing page currently also hardcodes the same hex values inline.
- `npm run build` prints two daisyUI 5 "Invalid empty selector" CSS warnings (`@scope`/`@media`). They are harmless; the build still succeeds.
